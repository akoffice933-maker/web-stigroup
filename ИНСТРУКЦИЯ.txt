2.1. СОЗДАЙТЕ ФАЙЛ submit.php

Создайте файл submit.php в корне сайта со следующим содержимым:

<?php
// submit.php - Обработчик форм для STI Group
// Разместите в корне сайта (рядом с index.html)

header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: POST');

if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    http_response_code(403);
    echo json_encode(['success' => false, 'message' => 'Forbidden']);
    exit;
}

// Получаем и очищаем данные
$name = htmlspecialchars(trim($_POST['name'] ?? ''));
$phone = htmlspecialchars(trim($_POST['phone'] ?? ''));
$email = htmlspecialchars(trim($_POST['email'] ?? ''));
$comment = htmlspecialchars(trim($_POST['comment'] ?? ''));
$form_type = htmlspecialchars(trim($_POST['form_type'] ?? 'callback'));

// Данные из калькулятора
$task = htmlspecialchars(trim($_POST['task'] ?? ''));
$equipment = htmlspecialchars(trim($_POST['equipment'] ?? ''));
$size = htmlspecialchars(trim($_POST['size'] ?? ''));
$installation = htmlspecialchars(trim($_POST['installation'] ?? ''));
$address = htmlspecialchars(trim($_POST['address'] ?? ''));

// Простая валидация
if (empty($name) || empty($phone)) {
    http_response_code(400);
    echo json_encode(['success' => false, 'message' => 'Заполните имя и телефон']);
    exit;
}

// Проверка телефона (простая)
if (!preg_match('/^[0-9\+\-\(\) ]{10,20}$/', $phone)) {
    http_response_code(400);
    echo json_encode(['success' => false, 'message' => 'Некорректный телефон']);
    exit;
}

// НАСТРОЙКИ ПОЧТЫ
$to = 'info@stigroup.ru'; // ← ЗАМЕНИТЕ на ваш email для заявок
$subject = "🔥 Заявка с сайта STI Group: $form_type";

// Формируем сообщение
$message = "
<html>
<head>
    <meta charset='utf-8'>
    <style>
        body { font-family: Arial, sans-serif; }
        .header { background: #2563eb; color: white; padding: 20px; }
        .content { padding: 20px; }
        .label { font-weight: bold; color: #0f172a; }
        .value { color: #1e293b; margin-bottom: 10px; }
    </style>
</head>
<body>
    <div class='header'>
        <h1>Новая заявка с сайта</h1>
    </div>
    <div class='content'>
        <p><span class='label'>Тип формы:</span> <span class='value'>$form_type</span></p>
        <p><span class='label'>Имя:</span> <span class='value'>$name</span></p>
        <p><span class='label'>Телефон:</span> <span class='value'>$phone</span></p>
        <p><span class='label'>Email:</span> <span class='value'>" . ($email ?: 'не указан') . "</span></p>
        <p><span class='label'>Комментарий:</span> <span class='value'>" . ($comment ?: 'нет') . "</span></p>
        <hr>
        <p><span class='label'>Дата:</span> <span class='value'>" . date('d.m.Y H:i') . "</span></p>
        <p><span class='label'>IP:</span> <span class='value'>" . $_SERVER['REMOTE_ADDR'] . "</span></p>
    </div>
</body>
</html>
";

$headers = "MIME-Version: 1.0\r\n";
$headers .= "Content-type: text/html; charset=utf-8\r\n";
$headers .= "From: STI Group <noreply@stigroup.ru>\r\n";
$headers .= "Reply-To: $email\r\n";
$headers .= "X-Mailer: PHP/" . phpversion();

// Отправка письма
if (mail($to, $subject, $message, $headers)) {
    // Можно сохранить в файл для резерва
    $log_entry = date('Y-m-d H:i:s') . " | $form_type | $name | $phone | $email\n";
    file_put_contents('leads.log', $log_entry, FILE_APPEND);
    
    echo json_encode(['success' => true]);
} else {
    http_response_code(500);
    echo json_encode(['success' => false, 'message' => 'Ошибка отправки письма']);
}
?>

```javascript
// Имитация отправки для демо

setTimeout(() => {
    // Показываем модалку успеха

    submitBtn.textContent = originalText;
    submitBtn.disabled = false;
    form.reset();
    
    if (typeof ym !== 'undefined') {
        ym(XXXXXXXX, 'reachGoal', 'form_submit');
    }

```

НА этот:

```javascript
submitBtn.textContent = 'Отправка...';
submitBtn.disabled = true;

const formData = new FormData(form);
formData.append('form_type', modalId.replace('modal-', ''));

fetch('/submit.php', {
    method: 'POST',
    body: formData
})
.then(response => response.json())
.then(result => {
    if (result.success) {
        if (modalId) closeModal(modalId);
        openModal('modal-success');
        form.reset();
        
        if (typeof ym !== 'undefined') {
            ym(XXXXXXXX, 'reachGoal', 'form_submit');
        }
    } else {
        alert('Ошибка: ' + result.message);
    }
})
.catch(error => {
    alert('Ошибка отправки. Попробуйте позже.');
    console.error('Error:', error);
})
.finally(() => {
    submitBtn.textContent = originalText;
    submitBtn.disabled = false;
});
```

5. ТЕХПОДДЕРЖКА И ВОЗМОЖНЫЕ ПРОБЛЕМЫ
================================================================================

ПРОБЛЕМА: Формы не отправляются
РЕШЕНИЕ:
1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь, что submit.php загружен на сервер
3. Проверьте права доступа к файлу (644)
4. Проверьте логи сервера

ПРОБЛЕМА: Метрика не показывает цели
РЕШЕНИЕ:
1. Убедитесь, что номер счётчика указан верно
2. Проверьте, что цели созданы в интерфейсе Метрики
3. Подождите 1-2 минуты после тестового события
4. Проверьте консоль на ошибки JavaScript

ПРОБЛЕМА: Письма не приходят
РЕШЕНИЕ:
1. Проверьте папку Спам
2. Убедитесь, что email в $to указан верно
3. Проверьте настройки сервера (функция mail())
4. Рассмотрите использование SMTP или PHPMailer

ПРОБЛЕМА: Сайт не открывается на GitHub Pages
РЕШЕНИЕ:
1. Проверьте настройки: Settings → Pages → Source: gh-pages branch
2. Подождите 2-5 минут после пуша
3. Очистите кэш браузера (Ctrl+Shift+R)
4. Проверьте https://github.com/akoffice933-maker/web-stigroup/actions
