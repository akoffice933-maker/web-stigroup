# 🚀 STI Group WordPress Theme — Инструкция по установке

## ✅ Что включено

Создана полноценная WordPress-тема с дизайном из твоего лендинга:

### Файлы темы:
- `style.css` — Все стили (glassmorphism, градиенты, анимации)
- `functions.php` — Функции темы, регистрация меню, настройка Customizer
- `header.php` — Шапка с навигацией и логотипом
- `footer.php` — Подвал с контактами и соцсетями
- `front-page.php` — Главная страница (Hero, Продукция, Калькулятор, Решения, CTA)
- `index.php` — Шаблон для блога/архивов
- `single.php` — Страница записи
- `page.php` — Страница без сайдбара
- `search.php` — Результаты поиска
- `searchform.php` — Форма поиска
- `404.php` — Кастомная страница 404
- `assets/js/main.js` — JavaScript (parallax, анимации, мобильное меню)

## 📦 Установка темы

### Вариант 1: Через админку WordPress (рекомендуется)

1. **Заархивируй папку** `sti-group-theme` в ZIP
   ```
   sti-group-theme.zip
   ```

2. **В админке WordPress:**
   - Внешний вид → Темы → Добавить новую
   - Нажми «Загрузить тему»
   - Выбери `sti-group-theme.zip`
   - Нажми «Установить»

3. **Активируй тему**
   - Внешний вид → Темы → STI Group → Активировать

### Вариант 2: Через FTP

1. **Скопируй папку** `sti-group-theme` в:
   ```
   /wp-content/themes/sti-group-theme/
   ```

2. **Активируй тему:**
   - Внешний вид → Темы → STI Group → Активировать

## ⚙️ Настройка после установки

### 1. Создай меню

1. **Внешний вид → Меню**
2. Создай новое меню (например, «Главное»)
3. Добавь страницы:
   - Главная (или якоря: #products, #solutions, #calculator, #contacts)
4. Выбери расположение: **Primary Menu**
5. Сохрани

### 2. Настрой контакты

1. **Внешний вид → Настроить → Contact Information**
2. Заполни:
   - Phone Number: `+7 (999) 123-45-67`
   - Email: `info@stigroup.ru`
   - Address: `Сочи, ул. Примерная, 123`
3. Сохрани изменения

### 3. Загрузи логотип

1. **Внешний вид → Настроить → Свойства сайта**
2. В разделе **Логотип** нажми «Выбрать логотип»
3. Загрузи свой логотип (рекомендуется 400×100px, PNG с прозрачным фоном)
4. Сохрани

### 4. Настрой главную страницу

1. **Настройки → Чтение**
2. Выбери: **Статическую страницу**
3. Главная страница: выбери страницу «Главная» (или создай новую)
4. Сохрани

### 5. Добавь товары (опционально)

Для добавления товаров с ценами и характеристиками:

**Способ A: Плагин (рекомендуется)**
- Установи плагин **Custom Post Type UI** + **Advanced Custom Fields**
- Создай CPT «Products» с полями: `price`, `features`

**Способ B: Кодом**
Добавь в `functions.php` вашей темы код из `README.md` (раздел «Товары»)

### 6. Замени изображения

1. Положи свои фото в папку:
   ```
   /wp-content/themes/sti-group-theme/assets/images/
   ```
2. Или используй WordPress Медиафайлы и обнови пути в `front-page.php`

## 🎨 Кастомизация дизайна

### Изменение цветов

Открой `style.css` и найди:

```css
.text-gradient {
    background: linear-gradient(135deg, #fff 0%, #a5b4fc 50%, #c084fc 100%);
}

.btn-primary {
    background: linear-gradient(135deg, #6366f1 0%, #8b5cf6 100%);
}
```

Замени цвета на свои.

### Изменение шрифтов

В `functions.php` найди строку с Google Fonts и замени:

```php
wp_enqueue_style('sti-group-google-fonts', 
    'https://fonts.googleapis.com/css2?family=Montserrat:wght@300;400;500;600;700&display=swap',
    ...
);
```

## 🔧 Деплой на хостинг

### WordPress.com (платный тариф)

1. Дашборд WordPress.com → твой сайт
2. **Развёртывания → Connect repository**
3. Авторизуйся в GitHub
4. Выбери репозиторий с темой
5. Настрой automatic deploy

### Свой хостинг (Beget, Timeweb, VPS)

**Через Git + SSH:**

```bash
# На сервере
cd /var/www/html/wp-content/themes/
git clone https://github.com/your-username/sti-group-theme.git
```

**Через GitHub Actions:**

Создай `.github/workflows/deploy.yml`:

```yaml
name: Deploy Theme

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Deploy via rsync
        uses: burnett01/rsync-deployments@5.2
        with:
          switches: -avzr --delete --exclude='node_modules'
          path: sti-group-theme/
          remote_path: /var/www/html/wp-content/themes/sti-group-theme/
          remote_host: ${{ secrets.HOST }}
          remote_user: ${{ secrets.USER }}
          remote_key: ${{ secrets.SSH_KEY }}
```

## 🐛 Если что-то не работает

### Не отображаются стили
- Очисти кэш браузера (Ctrl+F5)
- Проверь, что `style.css` загружается (F12 → Network)

### Не работает меню
- Проверь, что меню назначено на расположение «Primary Menu»
- Пересохрани меню

### Не отображаются товары
- Создай несколько записей типа Product
- Или заполни данные в `front-page.php` (секция $default_products)
