## Рекомендации по оптимизации

1. **Конвертируйте в WebP** для лучшей производительности
2. **Используйте сжатие** без потерь (TinyPNG, Squoosh)
3. **Добавьте srcset** для разных размеров экранов
4. **Lazy loading** для изображений ниже первого экрана
