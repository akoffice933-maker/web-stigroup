## 4. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### 4.1. Стек технологий
- **Вёрстка:** HTML5, CSS3 (с использованием Tailwind CSS, как на основном сайте ita-sochi).
- **Интерактивность:** Чистый JavaScript (ES6+) без тяжёлых фреймворков.
- **Адаптивность:** Mobile First, корректное отображение на всех устройствах (320px → 1920px).
- **Мобильное меню:** На устройствах с шириной < 768px главное меню сворачивается в бургер-иконку (три полоски). При клике открывается с анимацией slide-in справа, фон затемняется. Закрытие по крестику или клику на фон.

### 4.2. Интерактивные элементы
- **Фиксированная кнопка CTA:**
  - В правом нижнем углу страницы (position: fixed, bottom: 32px, right: 32px) разместить круглую синюю кнопку `Рассчитать стоимость` (белая иконка калькулятора внутри).
  - Размер: 64×64px на десктопе, 56×56px на мобильных (на мобильных bottom: 16px, right: 16px).
  - Появляется после прокрутки страницы на 30–40% (opacity 0 → 1 с transition 0.3s).
  - При клике открывает модальное окно с упрощённым калькулятором (блок 3).
- **Модальные окна:**
  - Открываются по клику на любую кнопку «Рассчитать стоимость», «Заказать», «Подробнее».
  - Закрытие: по крестику, по клику на затемнённый фон, по клавише Esc.
  - Анимация появления: fade-in + scale 0.95 → 1 (transition 0.3s).
  - После успешной отправки формы — модалка успеха: «Спасибо! Мы свяжемся с вами в течение 15 минут» + кнопка «Закрыть».
- **Плавный скролл:** Все якорные ссылки должны вести к блокам плавно (scroll-behavior: smooth).

### 4.3. Оптимизация и скорость (Core Web Vitals)
- **Изображения:** Все изображения в формате WebP, с указанием атрибутов width и height для резервирования места (CLS < 0.1). Использовать lazy loading (`loading="lazy"`) для изображений ниже первого экрана.
- **Видео (если используются):** Формат MP4/WebM, размер не более 5 МБ, атрибуты autoplay + muted + loop, на мобильных — playsinline.
- **Минификация:** CSS и JS должны быть минимизированы.
- **Шрифты:** Подключены с `display=swap` для предотвращения мигания невидимого текста (FOUT).

### 4.4. Формы и отправка данных
- **Обработчик:** Все формы отправляются методом POST на существующий `submit.php` (или другой обработчик, используемый на сайте ita-sochi).
- **Валидация:** На стороне клиента (JavaScript) проверять заполнение обязательных полей (имя, телефон). На стороне сервера — стандартная защита от спама.
- **Сообщения:** После отправки показывать пользователю уведомление об успехе или ошибке (без перезагрузки страницы). Ошибки выделяются красным цветом (`#ef4444`).

### 4.5. SEO-требования
- **Title:** `Интерактивные панели и киоски под ключ в Сочи — STI Group`
- **Meta Description:** `STI Group — производство и монтаж сенсорного оборудования в Сочи. Интерактивные панели, киоски, плёнки. Монтаж за 3 дня. Гарантия до 36 месяцев. Рассчитать стоимость онлайн.` (150-160 символов)
- **Заголовки:** Только один H1 на странице.
- **Alt-тексты:** Все изображения должны иметь осмысленный alt-текст.
- **Микроразметка:**
  - Для блока FAQ добавить разметку JSON-LD (Schema.org/FAQPage).
  - Для карточек товаров (блок 2) добавить JSON-LD Schema.org/Product (name, description, offers).

### 4.6. Аналитика и пиксели
- Подключить счётчики Яндекс.Метрики и Google Analytics (коды предоставит заказчик).
- Настроить цели:
  - Отправка формы (любой)
  - Клик по кнопке «Рассчитать стоимость» (включая фиксированную кнопку)
  - Скролл до блока FAQ (глубина 70%)
  - Просмотр блока каталога (оставаться на странице > 15 сек)

### 4.7. Доступность (Accessibility / WCAG 2.1 AA)
- Контраст текста и фона не ниже 4.5:1 (проверено инструментами).
- Все кнопки и ссылки имеют видимый фокус-стиль (outline: 2px solid #2563eb).
- У иконок без текста присутствует атрибут `aria-label` с описанием.
- Использование семантических тегов: `<main>`, `<section>`, `<article>`, `<nav>`, `<header>`, `<footer>`.
- Формы имеют связанные `<label>` для каждого поля.

### 4.8. Кроссбраузерность
- Последние 2 версии: Chrome, Firefox, Safari, Edge (включая мобильные версии).
